# Порівняння алгоритмів пошуку підрядка

У цій роботі було порівняно швидкість роботи трьох алгоритмів пошуку підрядка:

- Кнута-Морріса-Пратта (KMP)
- Боєра-Мура
- Рабіна-Карпа


## Як проводилось тестування

Для кожного тексту перевірявся пошук:

- слова на початку тексту;
- слова приблизно в середині;
- слова ближче до кінця;
- підрядка, якого в тексті взагалі немає.

### Використані підрядки

#### Article 1

| Позиція | Підрядок |
|---|---|
| Початок | `Вінницький` |
| Середина | `запускаємо` |
| Кінець | `Вікіпедія` |
| Відсутній | `кітпес` |

#### Article 2

| Позиція | Підрядок |
|---|---|
| Початок | `Центральноукраїнський` |
| Середина | `збалансованим` |
| Кінець | `implementation` |
| Відсутній | `бонжур` |

Для вимірювання часу використовувався модуль `timeit`. Кожен алгоритм запускався 1000 разів для кожного підрядка, щоб результати були більш стабільними та менш залежали від випадкових факторів.
Усі результати вимірювань наведені у секундах.

## Аналіз результатів
- Найшвидше алгоритми знаходили слова, які були на початку тексту.
- Для слів у середині та наприкінці тексту час виконання збільшувався, тому що алгоритмам потрібно було переглядати більшу частину тексту.
- Найбільше часу займав пошук вигаданого підрядка, якого немає в тексті. У такому випадку алгоритми фактично проходили весь текст до кінця.
- Найкраще себе показав алгоритм Боєра-Мура. Особливо це помітно на довших текстах, де завдяки механізму зсувів він може пропускати частину символів і виконувати менше перевірок.
- Алгоритм Кнута-Морріса-Пратта (KMP) показав досить стабільні результати незалежно від розташування підрядка. Алгоритм не повертається назад по тексту й працює передбачувано навіть у гірших випадках.
- Алгоритм Рабіна-Карпа в більшості тестів був трохи повільнішим через додаткові обчислення хешів.

## Висновок

Під час тестування найшвидшим у більшості випадків виявився алгоритм **Боєра-Мура**.
